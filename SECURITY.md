# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 10.0+   | :white_check_mark: |
| < 10.0  | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within this project, please report it responsibly:

1. **Do not** report security issues through public GitHub issues, pull requests, or discussions.
2. Please report the issue privately using GitHub's **Private Vulnerability Reporting** feature on this repository.
3. Include detailed steps to reproduce the issue, sample input/payloads, and device information.

We appreciate your cooperation in keeping this project secure.
